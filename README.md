# Popbros Industries: homepage redesign concept

A demo homepage for [Popbros Industries](https://www.popbros.com/), manufacturers of braided, knitted and woven elastics, cords and trims since 1963.

- `index.html`: the current design (light, corporate, with scroll and hover motion built on GSAP and Lenis)
- `concept-dark-v1.html`: the earlier dark concept, kept for reference
- `assets/`: logo, product photos and certification badges taken from popbros.com

Open `index.html` in a browser to view it. It needs an internet connection for fonts and the animation libraries.
